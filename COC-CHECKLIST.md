# Author Checklist

Complete this and commit it to your repository as COC-CHECKLIST.md. Summarize the testing items on your mod page.

| **Item**                                                                                | **Where it goes**    |
| --------------------------------------------------------------------------------------- | -------------------- |
| ☐ AI tags applied accurately (1.1)                                                      | Mod page             |
| ☐ Plain-language description of AI use (1.2)                                            | Mod page             |
| ☐ If tagged AI Assisted: development history and understanding available (1.3)          | Repository           |
| ☐ Source is public and linked (2.1)                                                     | Mod page, README     |
| ☐ Download built from a tagged commit (2.2)                                             | Release notes        |
| ☐ Game(s) and game versions tested (4.1, your game's file in `games/`)                  | Mod page             |
| ☐ Framework and dependency versions tested (5.5, your game's file in `games/`)                                        | Mod page             |
| ☐ Tested on a new save and an existing save (4.2)                                       | Mod page             |
| ☐ Removal tested; effect on saves stated (4.4)                                     | Mod page             |
| ☐ Log checked for errors and warnings (4.4)                                             | Mod page             |
| ☐ Performance impact checked (4.4)                                                      | Mod page             |
| ☐ Network, data and file access reviewed and disclosed (5.1–5.4)                        | Mod page             |
| ☐ Dependencies verified as real and legitimate (5.5)                                    | Repository           |
| ☐ Capability check run; every hit removed or disclosed (5.6, your stack file)                       | Mod page, repository |
| ☐ No knowingly copied code; sources credited; no game assets shipped (6.1, 6.4)         | Repository           |
| ☐ Thumbnails and screenshots are real gameplay (7.1, 7.2)                               | Mod page             |
| ☐ Description written by the author; LLM used only for proofreading or formatting (7.3) | Mod page             |
| ☐ Support status stated (3.3)                                                           | Mod page             |
